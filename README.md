# Saeed Ibn Dhayfallah — الموقع الشخصي

موقع شخصي عربي متجاوب، مبني باستخدام HTML وCSS دون أدوات بناء أو حزم إضافية.

## التشغيل المحلي

من مجلد المشروع:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

افتح الموقع محليًا في المتصفح على المنفذ 8000. لإيقاف الخادم اضغط Ctrl+C.

## التخصيص

- عدّل الاسم والنبذة والأعمال ووسائل التواصل في `index.html`.
- عدّل الألوان والتنسيق في `assets/style.css`.
- المحتوى يقدّم سعيد كمستشار وشريك في تطوير الإدارة والموارد البشرية، دون سرد الوظائف أو سنوات العمل.
- الشعار في `assets/logo.png` والتواصل عبر البريد الإلكتروني وواتساب.
- البريد الإلكتروني وواتساب مضافان كرابطَي تواصل؛ لم تُضف نسخة السيرة القابلة للتنزيل.
- الخط العربي يُحمّل من Google Fonts عند توفر الإنترنت، مع خطوط بديلة تعمل دون اتصال.

يمكن نشر الملفات كما هي على أي استضافة للمواقع الثابتة. الموقع لم يُنشر بعد.

## النشر على GitHub Pages

ملف `.github/workflows/pages.yml` جاهز للنشر عند رفع المشروع إلى فرع `main`، أو تشغيله يدويًا من Actions.

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. في المستودع افتح Settings ثم Pages.
3. اختر GitHub Actions في خانة Source.
4. من Actions شغّل Publish personal website، واختر فرع الملفات إذا شغّلته يدويًا.
5. بعد نجاح النشر يظهر رابط الموقع في نتيجة مهمة Deploy website وفي صفحة Pages.

تتوقف إتاحة Pages على إعدادات المستودع وخطة GitHub. تجهيز ملف النشر محليًا لا ينشر الموقع تلقائيًا.
